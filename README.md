# Personal Task Tracker

A Java command-line task tracker for the SDT 301 Software Enterprise term project.

## Project Goal

This project demonstrates professional software engineering practices through a small CLI application:
Git workflow, unit testing, CI, static analysis, design patterns, refactoring, and software metrics.

## Planned Features

- Create, list, update, and delete tasks
- Search tasks by keyword
- Filter by priority, status, and date
- Sort by due date and priority
- Persist tasks to a JSON file
- Export tasks to JSON and CSV
- Show task statistics

## Requirements

- Java 17+
- Gradle
- IntelliJ IDEA recommended

## Run

```bash
gradle run
```

## Test

```bash
gradle test
```

## Quality Checks

```bash
gradle check
```
